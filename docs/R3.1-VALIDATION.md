## 2. New card dimensions and composition

At 1440/1920, the five active cards are approximately **300×180px**, a 1.67:1 landscape proportion. Coming Soon cards are approximately **258×170px**, a 1.52:1 proportion. Widths scale with the stage at smaller desktop sizes and heights can grow with content. The active card minimum height is reduced from 290px; a wider text column, 37%-width side thumbnail and removed CTA row make comparison more efficient.

The existing stage shrinks from **1060px to 630px**. The centered eyebrow, editorial title and support line sit 18px above it. All seven complete positions, the heading and Menti fit together at the reviewed **1440×900, 1440×1000 and 1920×1080** sizes. The full section also includes controls, disclosure and bottom padding, and remains naturally scrollable; no viewport-fixed height, text clipping or hidden module information is used. The heading-to-last-card span is approximately 762px in the normal desktop captures.

## 3. Whole-card link implementation

All five featured cards are semantic anchors with descriptive names such as “Explore AI-Powered Career Counselling”, a single keyboard stop and no nested interactive control. The first three retain their existing story fragments.

Entrepreneurship and professional counselling previously opened availability notices rather than having program routes. They still open the same native notices on normal activation. Their new real fragment destinations reveal the same availability explanation below the stage without JavaScript or when modified-click navigation is used. This preserves honest preview behavior without inventing program routes. Dialogs remain siblings of the anchors, with the original Escape, focus containment and return-focus handling. The shared notice component's optional link mode is used only here; its default button mode is unchanged.

## 4. Explore Pathway removal

The repeated “Explore pathway” row, top rule and separate CTA control are removed from every active card. A small directional arrow remains inside the whole-card link. Every card's title and positioning copy are readable before hover. Existing shorter labels provide supporting copy; the owner-approved professional certification line remains on the counsellor card.

## 5. Menti size adjustment

Only ecosystem-scoped sizes change: **210→235px desktop (+11.9%)**, **168→190px tablet (+13.1%)**, and **144→162px mobile (+12.5%)**. The exact original SVG/component, cap, face, gradients and pupil architecture are reused. The redundant desktop caption is visually omitted to leave Menti central in the tight orbit; tablet/mobile keep the caption and connector. Hero Menti is untouched.

## 6. Orbital geometry changes

The existing SVG viewBox becomes 1120×630. Its four ellipses, seven curved connections and midpoint nodes are adjusted around the new stage center. Presentation coordinates preserve the approved top / upper sides / lower sides / bottom pair arrangement. Responsive percentage widths preserve spacing near the desktop breakpoint. No second orbit system, mascot or animation controller is added.

## 7. Path visibility and interaction

Default ring opacity rises from 0.30 to **0.46** and connection opacity from 0.25 to **0.38**; the active path remains **0.95** with its module accent and illuminated node. The environment remains predominantly navy/cyan/violet. Whole-card hover/focus activates the existing selection and bounded gaze, with reset on exit. Hover lift is reduced to **3px**, photograph scale to **2.5%**, and a restrained image overlay/edge glow strengthens the active surface. No layout expansion or new CTA appears.

## 8. Sticky-navbar clearance

Only section styling changes: 32px desktop top padding and no extra section scroll-margin, allowing the existing document scroll-padding to reserve the header's 88px footprint plus its 16px offset. The native anchor test checks title/top-card clearance and all card positions at 1440×900. The review screenshots are captured after fonts, hydration, reveals and scroll positioning settle; the title remains below the sticky rail. Shorter viewports can continue scrolling naturally.

## 9. Tablet and mobile

The existing 1100px carousel breakpoint, 44%-width tablet cards, 86%-width mobile cards, next previews, Previous/Next buttons, live position announcement and native swipe behavior remain. Compact top image crops suit the narrower cards. Minimum heights become **264px tablet / 284px mobile**, growing for longer copy as needed. Touch/focus/current-card changes retain Menti targeting. There is no auto-rotation. No-JavaScript grid/stack rendering and availability links remain usable.

## 10. Accessibility

The named section, ordered seven-position list and logical headings remain. Whole-card anchors have descriptive accessible names, visible gold focus outlines and large touch targets; they contain no nested controls. Coming Soon remains non-interactive, without href or tab stop. Decorative artwork/images remain hidden or have empty alternatives. Actual Tab, Enter, Escape, focus return, native touch input, overflow and axe WCAG 2.1 A/AA checks are covered. Automated scans supplement visual/keyboard review rather than establish universal conformance.

## 11. Reduced motion

Existing reduced-motion behavior disables gaze, character float/blink, thumbnail zoom and positional lift while retaining static focus/card/path feedback. The ecosystem's independent pause control remains. Original motion utilities, gaze limits and Hero pause/blink behavior are unchanged. Reduced-motion rendering is captured for review.

## 12. Performance

No dependency, font, image, remote asset, canvas, WebGL, video or motion library is added. Existing local responsive lazy thumbnails are retained; the desktop image-size hint is updated for the narrower photo column. The same lightweight SVG/CSS and section-scoped listeners/observer remain. There is no new continuous animation or backdrop-filter layer. No field performance benchmark was performed.
